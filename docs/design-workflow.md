# Flipbook 界面与交互约定

## 已选用的技能

- `frontend-design`：来自 `anthropics/skills` 的 `skills/frontend-design`，用于界面层次、布局和视觉评审。遵循技能目录中的 LICENSE.txt。
- `animations`：来自 `mthines/agent-skills` 的 `skills/design/animations`，用于交互反馈、减少动态效果和绘制开销的审查，MIT 许可。

技能安装在用户的 `~/.codex/skills/`，不是项目运行依赖。本轮没有新增动画或 3D 库。

## 设计方向

画册是视觉中心，控件保持安静。沿用现有字体，标题 18px、常用控件 12px、辅助文字 11px。正文与控件左对齐，预览作品居中。

导出区色板：纸面 `#ffffff`、预览台面 `#eceeec`、正文 `#202421`、辅助文字 `#626963`、分隔线 `#dfe3df`，键盘焦点 `#377258`。

桌面采用「作品预览 | 导出设置」双栏，设置滚动时保留预览，底部常驻选页摘要与导出操作；720px 以下改为单栏。预览高度随窗口高度收缩，避免遮挡操作区。

## 交互约定

- 同一次导出会话切换格式时保留选页、清晰度和排版选项；重新打开对话框恢复默认。
- 图片页按书中顺序组合。需要排除封面时使用“仅内页”。
- 相框预览可拖动，也可用方向键移动 1%；Shift + 方向键移动 5%；Home 重置位置与缩放。
- 空选页显示操作提示并禁用导出。加载、错误与导出进度向辅助技术提供状态。
- 连续参数更新的 Canvas 绘制合并到浏览器帧，卸载时取消待执行绘制。
- 进度条使用 `transform: scaleX()`，减少动态效果偏好下取消过渡；不添加持续装饰动画。

## 验证重点

类型检查、ESLint、现有测试；浏览器中检查短桌面窗口和 390px 窄屏、格式切换保留状态、键盘微调、末组预览以及空选页。
